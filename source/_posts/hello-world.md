Welcome to [Hexo](https://hexo.io/)! This is your very first post. Check [documentation](https://hexo.io/docs/) for more info.

## Quick Start

### Create a new post

```bash
$ hexo new "My New Post"
```

### Run server

```bash
$ hexo server
```

### Generate static files

```bash
$ hexo generate
```

### Deploy to remote sites

```bash
$ hexo deploy
```
